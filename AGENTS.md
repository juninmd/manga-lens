# AGENTS.md

Manga Lens: reader and translator for manga and comics (Bun server + web client, Tauri v2 desktop app). Translation is done by a multi-provider AI layer.

## Stack

- Runtime and server: Bun, TypeScript, Hono (`src/server/`).
- Client: TypeScript modules and CSS in `src/client/`, built by `scripts/build-client.ts` into `public/`.
- Desktop: Tauri v2 (`src-tauri/`), with a sidecar built by `scripts/build-sidecar.ts`.
- AI: Vercel AI SDK (`ai`, `@ai-sdk/openai-compatible`, `@openrouter/ai-sdk-provider`). Providers: `openrouter`, `ollama`, `openaicompatible`.
- Lint: Biome (`biome.jsonc`). Types: `tsc --noEmit` (`tsconfig.json`).

## Commands

```bash
bun install --frozen-lockfile   # setup (CI uses the frozen lockfile)
bun run dev                     # build client, then server with --watch
bun run start                   # build client, then server
bun run check                   # lint + typecheck + secrets + test (the local gate)
bun run lint                    # biome lint --error-on-warnings
bun run typecheck
bun run test                    # bun test tests --timeout 30000
bun run secrets                 # secret scan (history: secrets:history)
bun run smoke                   # scripts/smoke.ts
bun run desktop                 # tauri dev
bun run desktop:build           # client + sidecar + tauri build
```

CI (`.github/workflows/ci.yml`) runs lint, typecheck, secrets, test and `build:client`. `commits.yml` runs `scripts/check-commits.ts` against the base branch.

## Structure

- `src/server/`: Hono routes and AI provider code (`ai.ts`, `ai-body.ts`, `ai-config-body.ts`).
- `src/client/`: reader, library, OCR, TTS and settings UI (`reader.ts`, `lens.ts`, `ocr.ts`, `tts.ts`, ...).
- `src/shared/`: code shared by server and client.
- `tests/`: `bun test` suites. `tests/fixtures/` holds sample inputs.
- `scripts/`: build, release, smoke and benchmark scripts. `ocr-benchmark*.{mjs,py}` read `.workflow/5-competitive-quality/`.
- `src-tauri/`: desktop shell and sidecar config.
- `.workflow/`: benchmark data (ground truth, crops, research notes) used by scripts and linked from `README.md`. Do not delete it.
- `docs/`: `sources.md`, `sources-validation.json`, `evidence/` (PR screenshots).

## Conventions

- Commits: `tipo(escopo): descricao`, with a type from `TYPES` in `scripts/check-commits.ts`. Check with `bun run commits` before pushing.
- Keep API keys out of commits. The only tracked env file is `.env.example`, which has names and no values.

## Gotchas

- Env var names (values stay out of the repo): `PORT`, `LOCAL_LIBRARY`, `AI_PROVIDER`, `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL`, `AI_VISION_MODEL`, provider-specific `OPENROUTER_*`, `OLLAMA_*`, `OPENAI_COMPATIBLE_*`, TTS `KOKORO_*`, `PIPER_*`, `OPENAI_TTS_*`, `ELEVENLABS_*`. See `.env.example`.
- `public/` and `.cache/` are generated and gitignored. Run `bun run build:client` before serving the client.
- The tesseract model (`*.traineddata`) is downloaded on demand into `.cache/tessdata` and is not versioned.
- Desktop builds need Rust and the Tauri prerequisites. `src-tauri/binaries/` is generated by the sidecar build.
